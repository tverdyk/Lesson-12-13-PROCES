   Создание скрипта длявывода информации о PID, PPID, STATE  и CMD "имя или команды запуска"\
   Скрипт состоит из
  1) Переменной с выраженим для чтения каталога /proc для стения PPID. 

         get_ppid() {
             local pid=$1
             awk '{print $4}' "/proc/$pid/stat" 2>/dev/null
         }       

  2) Перменной для Загаловка вывода 

         printf "%-8s %-8s %-6s %s\n" "PID" "PPID" "STATE" "COMMAND"
         printf "%-8s %-8s %-6s %s\n" "-------" "-------" "-----" "----------------------------------------"
     

  3) Основного цикла для чтения параметров из задания.


            for pid_dir in /proc/[0-9]*/; do

              # Извлекаем PID
              pid=$(basename "$pid_dir")
              
              # Проверяем существование
              if [[ -d "/proc/$pid" ]]; then
                  # Получаем PPID
                  ppid=$(get_ppid "$pid")
                  
                  # Получаем состояние
                  state=$(awk '{print $3}' "/proc/$pid/stat" 2>/dev/null)
                  
                  # Получаем имя команды
                  cmd=$(cat "/proc/$pid/comm" 2>/dev/null)
                  
                  # Вывод строк в терминал для процессов
                  printf "%-8s %-8s %-6s %s\n" "$pid" "${ppid:-?}" "${state:-?}" "${cmd:-[unknown]}"
              fi
          done

Вданном скрипте есть неточности в виде некоректного вывода некоторых процессов, что абсолютно не мешает использовать данный скрипт в поиске нужных процессов.
